# FastTrack Frontend

React + TypeScript + Vite frontend for FastTrack Job Tracker.

## Setup

```powershell
cd frontend
npm install
npm run dev
```

Visit `http://localhost:3000` — the app will proxy API calls to `http://127.0.0.1:4000`.

## Features

- Clean, neutral design with light sage green accents
- Enter a job URL to extract job descriptions via Playwright MCP
- View structured job data: title, company, responsibilities, skills
- (Coming soon) Tailor resume and apply

## Build

```powershell
npm run build
```
